# Contributing to Melody

First off, thank you for considering contributing to Melody! It's people like you that make Melody such a great platform.

## How can I contribute?

### 1. Reporting Bugs
If you find a bug, please open an issue and include:
- Your operating system and browser version.
- Steps to reproduce the bug.
- Expected vs actual behavior.

### 2. Suggesting Enhancements
Have an idea for a cool new feature? Open an issue! Please provide as much detail as possible about what the feature should do and why it would be beneficial.

### 3. Submitting Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Code Style
We use ESLint for frontend styling and standard Go formatting for the backend. Please ensure your code conforms to these standards before opening a PR.

Thanks again for your support!
